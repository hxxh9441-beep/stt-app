# 🎙️ صوت → نص (STT Only)

تطبيق **تحويل الكلام إلى نص** — نسخة خفيفة ومحسّنة من المشروع الكامل:
- محرك **Whisper** (transformers.js) عبر **WebGPU/WASM** مع محدد وضع التوليد الثلاثي
- **أوفلاين بالكامل** بعد أول استخدام (النموذج يُخزَّن محلياً عبر Cache API)
- **Zero-Data**: لا يُرفع أي صوت أو نص — كل شيء على جهازك
- دعم التسجيل المباشر + رفع الملفات (MP3/WAV/M4A/WebM) + تصدير TXT/SRT
- واجهة عربي/إنجليزي داكنة + PWA قابل للتثبيت

## التطوير

```bash
npm install
npm run dev        # خادم التطوير
npm run build      # بناء الإنتاج (dist/)
npm run preview    # معاينة البناء
```

## النشر

المشروع جاهز للنشر على:
- **Cloudflare Pages** (Upload assets من `dist/` — رؤوس WebGPU موجودة في `public/_headers`)
- **GitHub Pages** (سير عمل تلقائي في `.github/workflows/deploy.yml` — فعّل Settings → Pages → Source: GitHub Actions)

## وضع التوليد

| الوضع | المحرك | ملاحظة |
|---|---|---|
| 🔄 التكيف الذكي | تلقائي | الافتراضي — يختار الأفضل لجهازك |
| ⚡ وضع التوليد الفائق | WebGPU | الأسرع — يتطلب متصفحاً يدعمه وترويسات أمان |
| 🛡️ وضع التوليد القياسي | WASM | يعمل على كل الأجهزة — مستقر وأوفلاين |

> ملاحظة: GitHub Pages لا يرسل ترويسات WebGPU المطلوبة، لذا سيعمل التطبيق هناك بوضع التوليد القياسي تلقائياً.
